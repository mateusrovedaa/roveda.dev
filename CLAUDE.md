## Agent skills

### Issue tracker

Issues vivem no GitLab Issues deste repositório (usando a CLI `glab`). Veja `docs/agents/issue-tracker.md`.

### Triage labels

Labels de triagem usam os nomes canônicos padrão (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). Veja `docs/agents/triage-labels.md`.

### Domain docs

Repositório de contexto único: `CONTEXT.md` na raiz + `docs/adr/`. Veja `docs/agents/domain.md`.

# Materiais

Coloque aqui qualquer arquivo que deve aparecer em /materiais.

- HTML (`*.html`) → renderizado dentro do site
- PDF (`*.pdf`) → visualizador com download
- Outros (zip, md, etc) → download direto

Exemplo:
```
public/materiais/
  aula01.html
  apostila.pdf
  roteiro/
    lab01.html
```

No próximo `pnpm build` a listagem é gerada automaticamente.

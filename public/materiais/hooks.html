Tela Viva

Como uma tela muda depois de desenhada: reage ao toque e ao que o usuário digita. Dois hooks do React fazem isso: useState e useEffect.

projeto da aula: 8-aula1809 · npm install && npm start
Parte 1 · O problema
1

A variável muda e a tela não

let nota = 8.5;

function aumentarNota() {
  nota = nota + 0.5;
}

<Text>{nota}</Text>
<Button title="Aumentar" onPress={aumentarNota} />

Ao tocar no botão, a variável vira 9, depois 9.5. A tela continua mostrando 8.5.

A tela é o resultado de executar a função do componente. Ela só muda quando a função executa de novo. Mudar uma variável comum não faz a função executar. Executar de novo a função de um componente chama-se re-render.

2

O que é um hook

Hook é uma função do React cujo nome começa com use. Ela dá ao componente algo que uma função comum não tem: guardar um valor entre um render e outro, ou executar algo depois de desenhar.

Duas regras:

  • Chamar só dentro da função do componente, antes do return. Nunca dentro de if, laço ou outra função.
  • Chamar sempre na mesma ordem. O React identifica cada hook pela posição em que foi chamado.

Três formas de JavaScript usadas neste material

Código Significado
const [a, b] = lista; a recebe o primeiro item da lista, b o segundo
() => { ... } função sem nome, definida no lugar em que é usada
onPress={aumentarNota} entrega a função ao botão, sem executar. O botão executa quando for tocado
Parte 2 · useState
3

Estado

Estado é um valor que muda com o tempo e aparece na tela. O React guarda esse valor entre renders e desenha a tela de novo quando ele muda. 

import { useState } from "react";

const [nota, setNota] = useState(8.5);
//     ↑ valor  ↑ função   ↑ valor inicial

useState devolve uma lista com dois itens. O primeiro é o valor atual. O segundo é a função que troca o valor. O argumento é o valor inicial, usado só no primeiro render. 

function aumentarNota() {
  setNota(nota + 0.5);
}

<Text>{nota}</Text>
<Button title="Aumentar" onPress={aumentarNota} />

setNota guarda o novo valor e faz o React executar a função do componente de novo. Nesse novo render, useState(8.5) devolve o valor guardado, não o 8.5.

Nunca escreva nota = 9. Só setNota(9) atualiza a tela.

4

Estado verdadeiro ou falso

O tipo do estado é o tipo do valor inicial.

const [mostrar, setMostrar] = useState(false);

function alternarDetalhes() {
  setMostrar(!mostrar);
}

const tituloBotao = mostrar ? "Esconder" : "Mostrar";

<Button title={tituloBotao} onPress={alternarDetalhes} />
{mostrar ? <Text>Detalhes</Text> : null}

!mostrar é o contrário de mostrar: true vira false e false vira true.

condição ? A : B vale A se a condição for verdadeira, B se for falsa. Dentro do JSX, não é possível usar if; é assim que se escolhe o que desenhar. null significa "não desenha nada".

5

Campo de texto

const [nome, setNome] = useState("");

function mudarNome(texto) {
  setNome(texto);
}

let saudacao = "Olá, Estudante";
if (nome !== "") {
  saudacao = "Olá, " + nome;
}

<TextInput value={nome} onChangeText={mudarNome} />
<Text>{saudacao}</Text>

value define o que o campo mostra. onChangeText é a função que o campo executa a cada tecla, recebendo o texto inteiro. Uma escreve no estado, a outra lê. Com as duas, o estado é a única fonte do que aparece no campo.

O if fica antes do return, onde qualquer código JavaScript é permitido. Dentro do JSX vai só o resultado.

Cada tela tem o próprio estado. O nome digitado no perfil não existe na tela inicial.

Parte 3 · useEffect
6

Efeito

Efeito é um código que executa depois que o React desenhou a tela. Exemplos: gravar no banco, buscar dados, escrever no terminal. 

import { useEffect, useState } from "react";

useEffect(() => {
  console.log("nota mudou para", nota);
}, [nota]);

Dois argumentos. O primeiro é a função que executa. O segundo é a lista de dependências: os estados que, ao mudar, fazem a função executar de novo.

Lista Quando executa
[nota] quando a tela abre e sempre que nota mudar
[] uma vez, quando a tela abre
sem lista depois de todo render
7

Limpeza

useEffect(() => {
  console.log("perfil abriu");

  return () => {
    console.log("perfil fechou");
  };
}, []);

A função devolvida com return é a limpeza. O React a executa quando a tela fecha.

Um efeito que liga algo (um cronômetro, uma conexão) precisa desligar na limpeza. Sem isso, o que foi ligado continua executando com a tela já fechada.

Parte 4 · Consulta
8

Erros comuns

O botão não muda a tela.
O código escreve nota = 9 em vez de setNota(9).
Erro: Too many re-renders.
onPress={aumentarNota()}, com parênteses. A função executa durante o render, muda o estado, causa outro render, e repete. Correto: onPress={aumentarNota}.
O efeito executa sem parar.
Efeito sem lista de dependências chamando um set. Adicione a lista.
Erro: Rendered more hooks than during the previous render.
Um hook dentro de if ou depois de um return. Mova para o início da função.
O TextInput não aceita digitação.
Tem value mas não tem onChangeText. O estado nunca muda, e o campo mostra sempre o mesmo valor.
